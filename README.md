# Bank English Mock Test

A single-file exam-style practice app (TCS iON style layout) for bank exam English.
Paste ChatGPT's formatted output and it converts into a timed test.

## Host on GitHub Pages
1. Create a new repository on GitHub (e.g. `bank-english-mock`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
4. After a minute your site opens at `https://<your-username>.github.io/bank-english-mock/`.

## Input format
```
TITLE: <short title>
PASSAGE:
<paragraphs>

Q1. <question>
A) ...
B) ...
C) ...
D) ...
E) ...
ANSWER: B
EXPLANATION: <one line>
```
